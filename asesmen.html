Tinjauan jawaban

Rekap untuk spreadsheet

Unduh data asesmen dalam format CSV. File dapat dibuka atau diimpor ke Google Sheets maupun Microsoft Excel.

Rekap per peserta

Satu baris per peserta: nama, kelas, waktu, jumlah benar/salah, skor, dan status setiap nomor.

Rincian per soal

Dua puluh baris per peserta: jawaban siswa, kunci jawaban, status benar/salah, level kognitif, dan skor soal.

  1. Buka Google Sheets dan buat spreadsheet baru.
  2. Pilih File → Impor → Upload, lalu unggah CSV yang diunduh.
  3. Pilih pemisah koma dan impor sebagai sheet baru. Ulangi untuk file rekap atau rincian.

Catatan: pada pratinjau ini pengiriman otomatis ke Google Sheets belum aktif karena konektor Google Drive/Sheets tidak tersedia. Ekspor CSV adalah jalur pencatatan yang dapat digunakan sekarang.
